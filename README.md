# HR Analytics Dashboard (Tableau)

## Project Overview
This project is an interactive HR Analytics Dashboard built using Tableau.

The dashboard analyzes:
- Employee count
- Attrition rate
- Promotion analysis
- Salary distribution
- Employee satisfaction
- Average monthly working hours
- Department-wise employee distribution

## Tools Used
- Tableau
- CSV Dataset
- Data Visualization

## Dashboard Features
- KPI Cards
- Bar Charts
- Histogram
- Interactive Dashboard
- Department Analysis
- Promotion Insights

## Key Insights
- Total Employees: 14,999
- Attrition Rate: 24%
- Sales department has the highest number of employees
- Most employees were not promoted in the last 5 years
